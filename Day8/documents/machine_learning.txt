Machine Learning (ML) is a subset of Artificial Intelligence (AI) that provides systems the ability to automatically learn and improve from experience without being explicitly programmed. ML focuses on the development of computer programs that can access data and use it to learn for themselves.

The primary categories of machine learning are:
1. Supervised Learning: Models are trained on labeled data where input-output pairs are provided. Examples include regression and classification.
2. Unsupervised Learning: Algorithms discover hidden patterns or data groupings without human intervention or labeled responses. Examples include clustering and dimensionality reduction.
3. Reinforcement Learning: Agents take actions within an environment to maximize cumulative reward through trial and error.

Key algorithms in machine learning encompass linear regression, logistic regression, decision trees, support vector machines (SVM), random forests, and gradient boosting methods.
